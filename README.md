# GFC 모집 랜딩페이지

김상철 GFC의 직무 설명 연결·모집 안내 페이지.

현재 버전: **2026-11-13 · v3 · 검토용 초안**

## 파일과 주소

- `index.html`: 최신 제작본. 실제 배포 도메인의 `/`에 해당합니다.
- `gfc-2026-11-13-v1.html`: 첫 초안 보존본.
- `gfc-2026-11-13-v2.html`: 네이비·화이트와 AI 연출 인물 이미지를 적용한 v2 고정본.
- `gfc-2026-11-13-v3.html`: 브랜드 텍스트와 블루 컬러, 소개·업무 영역·교육 안내를 보강한 최신 고정본.
- `BENCHMARK-v3.md`: 레퍼런스 확인 및 적용 기록.
- `hero-2026-11-13-v2.png`, `scenes-2026-11-13-v2.png`: 버전 고정 이미지.
- `IMAGE-NOTES-v2.md`: 생성 방식·장면·품질 확인 기록.
- `versions.html`: 버전별 페이지 목록.
- `versions.json`: 날짜, 버전, 설명, 상태, 최신본 관리.
- `new-version.py`: 기존 페이지를 보존하며 새 초안을 만드는 도구.
- `LAUNCH-CHECKLIST.md`: 실제 접수·공개 전 확인 항목.
- `CHANGELOG.md`: 변경 기록.

각 랜딩페이지는 HTML 한 파일에 CSS와 JS를 포함합니다. v2의 이미지는 같은 폴더의 버전 고정 PNG를 함께 보관합니다. 이전 버전은 이후 CSS·설정 변경의 영향을 받지 않습니다. 패키지 설치나 빌드가 필요하지 않습니다.

## 로컬 미리보기

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765/`를 엽니다. 버전 목록은 HTTP로 열면 `versions.json`을 읽습니다.

## 상담 버튼

각 랜딩페이지 하단 `SETTINGS`에 연결 주소가 있습니다.

- `formUrl`: 생성된 구글폼의 응답자 주소. 상담 신청 버튼에 적용됩니다.
- `kakaoUrl`: 현재 빈 값이므로 실시간 상담 버튼이 **전송·저장 없는 목업**을 엽니다.
- 실제 1:1 오픈채팅 생성 후 `kakaoUrl`에 `https://open.kakao.com/...` 주소를 설정하면 실제 채널을 엽니다. 그때 목업 안내·FAQ도 함께 갱신합니다.

구글폼과 응답 시트는 생성·연결했습니다. **폼은 미게시·접수 중지 상태**이며, 개인정보 처리 주체·보유기간·전달 방식 및 동의문 확정 후 운영자가 게시해야 합니다. 랜딩페이지에도 준비 중임을 표시했습니다. 공개 소스에는 응답자 링크만 포함하고 편집 링크·시트 링크·신청자 정보·키를 넣지 않습니다.

## 새 버전 만들기

```sh
python3 new-version.py --date 2026-11-20 --version v2 --title '경력 활용형 두 번째 초안'
```

이 명령은 새 고정본을 생성하고 버전 목록과 최신 `index.html`을 갱신합니다. 이후 새 고정본을 수정했다면 같은 내용을 `index.html`에 복사하세요. 기존 고정본은 수정하지 않는 것이 원칙입니다. 개인정보 노출이나 중요한 오류는 과거 페이지도 즉시 수정·중단합니다.

단순 오탈자·버그 수정은 Git 커밋과 CHANGELOG로 남기고, 문구·타깃·신청 흐름 변경은 새 버전으로 보존합니다. 새 페이지의 status는 항상 draft로 시작합니다. approved 등 상태를 바꾸기 전 승인 근거를 별도로 보관하세요.

## 배포

이 저장소는 코드 관리용입니다. 이번 작업에서는 GitHub Pages나 다른 호스팅을 활성화하지 않았습니다. 향후 서비스 약관·모집 표현·브랜드 사용·개인정보 처리 방식을 확인한 뒤 배포처를 정합니다. 검토용 페이지에는 검색 노출 방지용 `noindex,nofollow`가 있습니다. 실제 공개 승인 후 필요에 따라 변경하세요. noindex는 접근 통제가 아니므로 개인정보를 포함하지 마세요.

## 콘텐츠 기준

- 기업 대상 보험·금융 **영업**, 위촉형, 성과형을 첫 화면·하단에 표시.
- 김상철 GFC는 초기 활동자로서 전화·일정 조율을 맡으며 교육 책임자로 묘사하지 않음.
- 소득·정착금·4대 보험·고객 배정·위촉 결과를 보장하지 않음.
- 다른 사이트의 문장·이미지·후기·동의문을 복사하지 않음.
- 운영자와 연결 역할을 밝히며 신문 기사 또는 확인되지 않은 본사 운영 페이지로 표현하지 않음.
- v3부터 사용자의 명시적 지시에 따라 ‘공식 사이트가 아닙니다’ 문구를 제거하고 ‘삼성생명 GFC’를 상단 브랜드 텍스트로 사용.
- 신청자 정보와 상담 기록은 공개 GitHub 저장소에 저장하지 않음.
